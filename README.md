# 🏸 Court Booking System (SM Sport Center)
## 📖 Deskripsi
Court Booking System adalah aplikasi berbasis web yang dirancang untuk memudahkan proses reservasi lapangan olahraga secara online. Sistem ini menyediakan fitur bagi pelanggan untuk melakukan pemesanan lapangan, mengunggah bukti pembayaran, serta memantau status reservasi. Administrator dapat mengelola data lapangan, pelanggan, reservasi, pembayaran, dan menghasilkan laporan.
Project ini dikembangkan sebagai implementasi sistem informasi berbasis web menggunakan PHP dan MySQL.
---

## ✨ Fitur
### Pelanggan

* Registrasi dan login
* Melihat daftar lapangan
* Melakukan reservasi lapangan
* Mengunggah bukti pembayaran
* Melihat riwayat reservasi
  
### Administrator
* Dashboard admin
* Manajemen data lapangan (CRUD)
* Manajemen data pelanggan
* Verifikasi pembayaran
* Melihat detail reservasi
* Laporan reservasi
---

## 👨‍💻 Pengembang
Dikembangkan sebagai project pembelajaran dan portofolio pengembangan aplikasi web menggunakan PHP dan MySQL.
